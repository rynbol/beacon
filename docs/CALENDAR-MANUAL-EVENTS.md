# Manual events in Next 7 days

Calendar → Next 7 days has an Add events picker, also available in Settings → Calendars → Manually added. It lists events omitted by keyword filters, from visible calendars within the rolling seven-day window. Search matches titles without case sensitivity. Each row shows its title, date, time/all-day status, and source calendar. Selecting a row immediately includes it and removes it from the available choices, allowing multiple picks without reopening the picker.

Manual selections override include and exclude keywords for that occurrence only. Calendar visibility and time-window rules still apply. Selections persist locally using the snapshot occurrence ID (calendar, event identifier, start time). A renamed event reflects its current title; deleted or expired events are not reconstructed from settings. A changed occurrence identifier or start time requires selecting that occurrence again. Removing a manual selection returns the event to normal keyword filtering; an independently matching event remains visible.

Calendar data remains read-only. No reminders or provider events are created or modified. Settings lists current in-window manual selections, including ones whose calendar is hidden, so they can still be removed.

Validation: 137 unit tests passed. Coverage includes keyword overrides, removing overrides, visibility and seven-day boundaries, recurrence/calendar scope, persistence encoding, no duplicate from an event matching both routes, renamed/deleted events, and existing case-insensitive matching. In the isolated sample preview, an excluded Dentist event was added through Settings, appeared in the agenda, survived app restart, and was removed successfully. Escape closed the picker without closing Settings. Test selections and keyword were removed afterwards. Both regular and preview Mac builds passed. The Settings layout was visually inspected; native popover controls were checked through accessibility because window screenshots omit that separate surface.
